# MODARA (مدارا)

Persian (RTL), mobile-first content operations management app.
React + Vite + TypeScript, Zustand, local-first (IndexedDB via Dexie, added in Batch 2).

## Run
```
npm install
npm run dev
```

## Checks
```
npm run typecheck
npm run lint
npm run build
```

## Status
Phase 1, Batch 1 done: design system, RTL/Persian setup, app shell, sample-data dashboard.
Dexie is installed but not used yet. The dashboard shows clearly marked sample data.
